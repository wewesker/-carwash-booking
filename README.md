# Автомойка: сайт с онлайн-записью

Одностраничный сайт автомойки: прайс, выбор бокса и времени, запись клиента и экран администратора.

- `index.html` — весь сайт (HTML, CSS и JS в одном файле). Название, адрес, телефон, часы, число боксов и цены меняются в блоке `CFG` и списке `SVC` в начале скрипта.
- `supabase/schema.sql` — таблица записей и функции базы (Supabase). Таблица закрыта для прямого доступа, сайт работает только через функции.
- Экран администратора: `…/#admin`, вход по коду доступа.

Хостинг: GitHub Pages. База: Supabase.
